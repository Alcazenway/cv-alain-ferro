# Alain Ferro — parcours détaillé

Vitrine professionnelle personnelle, sans dépendance distante ni collecte de données.
Version : 2.1 (6 novembre 2026). Navigation : Parcours, Savoir - formations, Compétences, Intérêts ; « Proposer un entretien » ouvre la messagerie du visiteur avec un message prérempli, sans envoi automatique.
Adresse publique stable : https://alcazenway.github.io/cv-alain-ferro/

Parcours : spirale interactive (spirale.js, spirale.css), naissance au centre, étapes du plus ancien au plus récent dans le sens horaire vers l’extérieur ; rotation très lente vers la droite (un tour en 600 s), libellés toujours horizontaux, pause, zoom, mouvement réduit respecté et vue liste équivalente. Les formations forment l’onglet séparé « Savoir - formations ».

Routes stables : `#/parcours/<id>`, `#/competence/<id>`, `#/parcours/exp-pro|projets-perso`, `#/savoir-formations`, `#/interets`, `#/realisations`, `#/mentions`. Anciennes adresses conservées : `#/contact` (accueil, actions de contact), `#/parcours/thermes-adjoint` (fiche fusionnée « Responsable d’équipe soignant »), `#/parcours/savoir` (onglet « Savoir - formations »), `#/parcours/enfance` et `#/parcours/adolescence` (fiches retirées en 2.1, renvoi vers le parcours).

Les photographies et visuels restent la propriété de leur auteur. Les logos identifient les outils de leurs éditeurs. Images et vidéos locales sont chargées à la demande.
